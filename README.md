# Precision IES Integration (public pages)

Static pages required by the Intuit Developer portal for the private **Precision IES
Integration** app built by Creative Planning Technology for Precision Underground Utilities, LLC.

| Page | Purpose (Intuit field) |
|---|---|
| `index.html` | Launch URL, host domain landing page |
| `eula.html` | End-user license agreement URL |
| `privacy.html` | Forwards to Creative Planning's privacy policy |
| `connect.html` | Connect / reconnect request URL |
| `disconnected.html` | Disconnect URL |
| `callback.html` | Production OAuth redirect URI; displays the auth code for copy-paste, sends nothing |

Published by GitHub Pages at `https://creative-planning.github.io/precision-ies-integration/`.

Generated by `Precision_Migration/scripts/build_public_site.py`. Edit there, rebuild, commit.
No client data, credentials, or personal contact details belong in this repo.
